# Data Cleaning, Analysis & Visualization with Excel

## 📊 Project Overview

This project is a complete Excel-based data analytics assignment using an e-commerce sales dataset.

The project covers the complete data analytics workflow, including:

- Data cleaning and transformation
- Missing-value handling
- Data validation
- Excel formulas
- XLOOKUP
- Descriptive statistics
- PivotTables
- PivotCharts
- Dashboard creation
- Slicers
- Data analysis and visualization

The project was completed using Microsoft Excel as part of the Module-End 1 assignment.

---

## 🎯 Objectives

The main objectives of this project were to:

- Clean and prepare raw datasets for analysis
- Identify and handle missing and inconsistent data
- Validate data quality
- Combine related datasets using XLOOKUP
- Perform calculations using Excel functions
- Generate descriptive statistics
- Analyze sales using PivotTables
- Create charts and PivotCharts
- Build an interactive sales dashboard
- Present the complete analysis in a clear and organized format

---

## 📁 Dataset

The project contains the following cleaned datasets:

- **Clean_Customer** – Customer information
- **Clean_Product** – Product information
- **Clean_Store** – Store information
- **Clean_Sales** – Sales transaction data

The main sales dataset contains fields such as:

- Sales_ID
- Order_Date
- Customer_ID
- Product_ID
- Store_ID
- Quantity
- Unit_Price
- Discount
- Payment_Type
- Total_Amount

---

## 🧹 Data Cleaning

Data cleaning was performed on the Customer, Product, Store, and Sales datasets.

The cleaning process included:

- Duplicate checking
- Missing-value identification
- Data validation
- ID standardization
- Text cleaning
- Removing unnecessary spaces using `TRIM()`
- Removing non-printable characters using `CLEAN()`
- Checking numeric values
- Checking date values
- Checking data consistency
- Validating Customer_ID, Product_ID, and Store_ID references

Missing values were reviewed and handled according to the dataset and assignment requirements.

---

## 🔗 XLOOKUP

XLOOKUP was used to enrich the Clean_Sales dataset with information from the related datasets.

The following fields were added:

This allowed the sales dataset to be analyzed using descriptive customer, product, and store information.
